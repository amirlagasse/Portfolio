Designing the ErgoSpooler Tension Limiter

Project Goal

The goals for this project were to create a system that will alert the user and have the ability to stop the machine using the E-stop wiring. Additionally, it was important to allow the user to choose between two options: alert or alert & stop. The final objective was to make the machine adjustable, allowing the user to set their desired tension.

Designing the Recoater Tension Limiter

Project Goal

The goals for this project were to be able to trick the recoater into reducing the minimum tension of 102g and to create a system where the user can set the desired tension to be removed. It was also important to design the limiter in a way that it does not interfere with the user while doing recoating or proof-testing. Finally, the system needed to be durable and not require any maintenance (i.e., a rubber band would wear down and eventually break).

Part Drawing with Dimensions

Adding ribs to improve the structural integrity of the parts to protect them against an accidental lateral impact, such as an operator bumping into the arm. With FEA, we can see that ribs increase the second moment of area of the cross-section, reducing peak stress by 74% under the same 100N lateral load.

Splice Statistics

Project Goal

The goals for this project were to figure out how the strength of the fiber changes when recoating, and to determine if there is a correlation between fiber cleave angle and measured dB loss, fiber cleave angle and fiber strength, and splicer’s recorded dB loss and measured dB loss. Another goal was to determine whether other factors improve dB loss and fiber strength.
